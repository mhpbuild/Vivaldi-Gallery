# Security policy

This is a hobby prototype. The current main branch is maintained on a best-effort basis; no response-time or security warranty is offered. There is no backend payment system and checkout is a simulation.

## Report a vulnerability privately

Use **Security → Report a vulnerability** on [the GitHub repository](https://github.com/mhpbuild/Vivaldi-Gallery/security). Include the affected commit, reproduction steps and impact. Do not include real credentials, personal audio files or unnecessary personal information. Do not disclose exploit details in a public issue before the maintainer can review them.

If private reporting is temporarily unavailable, open an issue requesting a private reporting channel without posting vulnerability details. The maintainer will arrange a channel before accepting sensitive information.

Rights or attribution corrections can be reported through a normal issue, provided no confidential material is included.
